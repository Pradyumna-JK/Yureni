# DealMind evaluation set

This directory contains a small, versioned gold set for DealMind's memory loop.
It is deliberately separate from the application test suite: unit tests mock
providers, while these checks call the running FastAPI service and therefore
exercise PostgreSQL, Hindsight, Ollama, retrieval, evidence selection, and
response validation together.

The first set targets the Acme demo bank. It checks factual answers, abstention,
evidence precision, source traceability, temporal change, and deal intelligence.
The expected terms are intentionally small semantic anchors rather than an
exact-answer string, because wording is generated by the configured local model.

Run it against a seeded, already-updated Acme deal:

```bash
python evals/run_api_eval.py \
  --deal-id 53df2f8b-70a7-4eeb-90e6-f4d8cb135cfc
```

For a clean temporal run, use a fresh deal and ingest the V1 and later
interactions first. The runner never writes memory or changes a deal. A JSON
report is printed to stdout and a nonzero exit code indicates a failed case.

The public benchmarks LongMemEval and LoCoMo are useful future comparative
benchmarks, but this gold set remains the product regression suite because it
tests sales concepts such as stakeholders, procurement gates, competitors,
pricing, objections, and next actions.
